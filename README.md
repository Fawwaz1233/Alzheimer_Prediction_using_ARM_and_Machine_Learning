# Alzheimer Prediction using ARM and Machine Learning

Proyek ini mengombinasikan **Association Rule Mining (ARM)** dengan algoritma *machine learning* untuk menganalisis dan memprediksi risiko Alzheimer. ARM digunakan untuk menemukan pola/asosiasi tersembunyi antar fitur klinis, yang kemudian memperkaya proses pemodelan prediktif.

## Isi Repository
- `Improve_Assignment_6.ipynb` — notebook utama: pra-pemrosesan data, analisis Association Rule Mining, pelatihan model machine learning, dan evaluasi.
- `Assignment_6_Report.pdf` — laporan tugas yang menjelaskan metodologi dan hasil analisis secara rinci.

## Metodologi
1. **Pra-pemrosesan data** — pembersihan dan transformasi data klinis pasien.
2. **Association Rule Mining (ARM)** — ekstraksi pola/aturan asosiasi antar variabel menggunakan algoritma seperti Apriori/FP-Growth.
3. **Machine Learning** — pelatihan model klasifikasi untuk memprediksi status Alzheimer berdasarkan fitur yang relevan.
4. **Evaluasi** — pengukuran performa model dengan metrik klasifikasi standar.

## Cara Menjalankan
1. Clone repository ini.
2. Buka `Improve_Assignment_6.ipynb` di Jupyter Notebook/Google Colab.
3. Jalankan seluruh sel secara berurutan untuk mereproduksi analisis ARM dan hasil prediksi.
4. Lihat `Assignment_6_Report.pdf` untuk pembahasan lengkap.
